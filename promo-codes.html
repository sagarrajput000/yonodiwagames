How it works

Three steps to redeem

1. Copy the code

Tap the code box. It is copied to your clipboard — paste it somewhere safe if you are switching devices.

2. Open the game

Use the download or claim button on the code card. It opens the operator's own site or app, where you register or log in as usual.

Enter the code in the promo, referral or bonus field before you deposit. Check the reward in the app before you play.
